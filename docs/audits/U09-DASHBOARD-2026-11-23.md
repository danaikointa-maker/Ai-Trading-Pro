Date: 2026-11-23  
Plan: Unified Master Plan V4 / Unified Task Register V4  
Branch: `feature/u09-chart-stability-v4`

## Gap and change

The V4 planning branch already had one `PriceChart.vue`, realtime candle updates,
and display toggles. It reset to `fitContent()` on every data reload, offered no
bounded zoom/follow controls, and drew order/position levels as price lines over
the entire chart. Position levels were not filtered by the chart symbol.

The same component now has bounded discrete zoom, a latest-candle follow toggle,
right-side chart shift and saved bar width. It stores the visible time range by
feed, symbol and timeframe and restores it only when the loaded candle range
covers the saved window. Manual panning pauses follow; a new live candle only
pulls the view forward while follow is enabled. Entry/SL/TP and open-position
levels use short canvas markers. Position overlays only match the selected
symbol or its dotted broker suffix; open-position data continues to come from
the existing fresh-position selector. No second chart, signal or position API
was introduced.

## Safety and rollback

All changes are visual preferences and read-only markers. The chart submits no
orders and changes no risk or broker setting. Existing backend routes and chart
feed selection remain in use. Rollback by reverting the U09 commit; there is no
database migration. `npm ci` reported three pre-existing dependency advisories
(2 moderate, 1 high); package versions were not changed.
