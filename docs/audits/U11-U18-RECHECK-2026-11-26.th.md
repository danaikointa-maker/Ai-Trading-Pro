## หลักฐานตรวจซ้ำ

### Local regression

คำสั่ง:

```text
& 'C:\workspace\Ai-Trading-Pro\.venv\Scripts\python.exe' -m pytest tests/test_tradingview_shadow_replay.py tests/test_tradingview_contract.py tests/test_tradingview_ingest.py tests/test_tradingview_persistence.py tests/test_paper_reconnect_recovery.py -q
```

ผล: **40 passed**, มี Starlette/httpx deprecation warning เดิม 1 รายการ. เป็น test ภายในเครื่อง/fixture เท่านั้น ไม่ยืนยัน broker, VM runtime, browser acceptance, load หรือผลการเทรดจริง

### Windows MT5

ตรวจ process `terminal64`/`metatrader` แบบ read-only: **ไม่พบ MT5 terminal process**. จึงไม่มี session หรือ quote สดให้ทดสอบในรอบนี้ และไม่ได้เปิด/สลับบัญชี

### Cloudflare และ VM100

- `https://agent.youridea168.com/`: HTTP **502**, TLS verify result **0** (ใบรับรองตรวจผ่าน แต่ origin ยังตอบไม่ได้)
- `systemctl is-active cloudflared`: `active`
- `ss -lntH`: ไม่มี listener ที่ `:8080`; Trading Pro listeners ที่พบเป็น loopback-only (`8000`, `18081`, `18082`)
- ไม่อ่าน `.env` หรือ tunnel config; ไม่ restart service, เปลี่ยน route/firewall/DNS, เปิดพอร์ต หรือแตะ secret ใด ๆ

3. ลำดับที่ปลอดภัยถัดไปคือจัดหา fresh Demo quote และหลักฐานอนุมัติสำหรับ U11; provision/review Office API + Keycloak/Vault identity สำหรับ U12; แก้ origin/Access และ security acceptance ของ U15 แยกจาก Trading Pro ports; จากนั้นจึงเก็บ corpus/visual/runtime receipts สำหรับ U16–U18

## Rollback

เอกสารอย่างเดียว ไม่มี schema/config/runtime change; rollback ได้ด้วยการ revert เอกสาร commit นี้ ไม่มีข้อมูล runtime ให้ย้อน
