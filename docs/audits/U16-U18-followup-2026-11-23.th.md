## ขอบเขต U16 evaluator

- รับ normalized Lens evidence, No7 decisions ที่มี `available_at_utc`, closed-bar OHLC timestamps และ symbol spec/cost assumptions โดยตรง; ไม่เชื่อม runtime/API/SQLite และไม่เพิ่ม endpoint, worker, DB, signal engine หรือ backtester.
- ใช้เฉพาะ symbol/timeframe/close ที่ตรงกัน; duplicate Lens หรือ No7 row จะไม่นำมาสรุปเป็นผลที่แน่นอน.
- นิยาม `t` เป็นเวลา UTC ปิดแท่ง. ราคาเข้าเป็น `open` ของแท่งแรกที่เวลาเปิดไม่น้อยกว่าเวลาที่ evidence/decision พร้อมใช้; ผลลัพธ์ใช้ `close` หลังครบจำนวนแท่งที่กำหนด จึงไม่นำแท่งสัญญาณหรือแท่งที่เริ่มก่อน alert มาใช้.
- หักต้นทุน points แบบคงที่จาก spread, slippage สองฝั่ง และ round-turn commission ที่ reference lot; ใช้ conversion/value-per-point ของ `SymbolSpec` และปฏิเสธ spec ที่ไม่ครบ, ไม่ได้มาจาก broker หรือแปลงสกุลเงินไม่ได้.
- รายงานเป็นผลการเคลื่อนราคาเชิงคาดการณ์ใน points เท่านั้น. **ไม่**จำลอง SL/TP, margin, intrabar ticks, fill, swap หรือผลการเทรดจริง; ห้ามใช้เป็นข้ออ้างความสามารถทำกำไรหรือป้อนกลับเข้าการตัดสินใจ.
- Repository ไม่มี historical Lens/No7 corpus พร้อมเวลาพร้อมใช้ และไม่มี historical variable-spread/slippage series ที่แนบกับ data snapshot จึงยังสร้างผลศึกษาเงินจริง/รับรองความได้เปรียบไม่ได้.
